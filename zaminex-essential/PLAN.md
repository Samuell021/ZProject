# طرح نمونه CRM املاک فردا
هدف: فهم مدل‌ها با یک گردش مشترک قابل اجرا از درخواست اولیه تا وصول جزئی کمیسیون.
مبنای اجرا: متن درخواست کاربر؛ پروپوزال ۱.۲ مرجع تکمیلی است. بک‌اند، مهاجرت داده واقعی و امنیت سرور در دامنه این نمونه نیست.
معماری: seed مرتبط → سرویس عملیات اتمیک با مجوز و اعتبارسنجی → Zustand و localStorage نسخه‌دار → صفحات React Router.
۱. داده: حداقل رکوردهای درخواست، روابط شناسه‌ای و سناریوهای ویژه.
۲. خدمات: ارجاع، کارشناسی، بررسی نسخه، تطبیق، معرفی، بازدید، پیشنهاد، قرارداد و مالی با تاریخچه مشترک.
۳. رابط: پوسته فارسی، مسیر مستقل جزئیات و فرم، کاریز و فهرست مشترک و راهنمای مدل‌ها.
۴. بررسی: آزمون چرخه اصلی و رد عملیات نامعتبر، ساخت خروجی، بررسی مرورگر و روابط seed.
تصمیم‌ها: JavaScript با JSDoc و اعتبارسنجی روابط، تاریخ استاندارد و نمایش شمسی، مبالغ تومان، شش رفتار مشخص بدون فرمول آزاد، امضای نمایشی.
تقسیم کار: عامل داده؛ عامل خدمات و آزمون؛ عامل صفحات پشتیبان؛ عامل اصلی پوسته و گردش اصلی و ادغام.
